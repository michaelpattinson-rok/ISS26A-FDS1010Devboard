# Arduino UNO R4 Minima recording catalog

This directory contains the Project and run manifests for the seven Uno recordings, a run index, and checksums for the complete native Project copy. The full dataset is 2.1 GB and is retained in the local Devboard E repository at `Data/UnoDataCollection`. This catalog does not contain raw samples or per-frame timing files.

The complete Project copy retains the original samples, frame timing, run annotations, and other saved artifacts. Open its `UnoDataCollection` folder in Signal Bench. For a received full copy, run `shasum -a 256 -c SHA256SUMS.txt` from the directory containing the Project folder and checksum list.
